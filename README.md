# 화물차 접근성 유형 분류 — 분석 파이프라인

트램 확정 노선 인근 분석 포인트(105개)를 대상으로, 비지도학습(계층적 군집화)을 통해
화물차 접근성 유형을 도출하고 정책 대응방안(A/B/C/저위험)을 매칭하는 파이프라인.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `pipeline_v3.py` | 데이터 정제 → 상관/VIF 진단 → 표준화 → 계층적 군집화(Ward) → 군집 해석 |
| `step10_policy.py` | 위험신호개수 산출 → 군집1(구조적 압박형) A/B 세부 유형 확정 |

## 실행 순서

```bash
pip install pandas numpy scikit-learn scipy matplotlib seaborn statsmodels

python pipeline_v3.py       # master_table.csv → outputs/final_result.csv 등
python step10_policy.py     # outputs/final_result.csv → outputs/final_result_v2.csv
```

## 입력 데이터

`master_table.csv` (cp949 인코딩), 분석 포인트(정거장·신호교차로·도로구조물 변화지점) 단위.

## pipeline_v3.py

### 처리 절차
1. 로드 및 결측치 확인
2. 이상치 확인 (제거하지 않고 데이터 오류만 점검)
3. 상관행렬 산출 (연속변수)
4. VIF 산출 (다중공선성 진단, 기준: <5 양호 / 5~10 확인 / ≥10 제거검토)
5. 표준화(StandardScaler)
6. 계층적 군집화(Ward) 덴드로그램 + 실루엣 점수(k=2~6)로 군집 수 결정
7. 군집화 실행
8. 군집별 변수 평균(프로파일) 산출
9. 결과 저장

### 군집화 투입 변수 (6개, 연속형만)
`차로 수`, `트램_차로감소율`, `TTI_차이_상행`, `TTI_차이_하행`, `최근접거리(m)`, `최근접주차장면수`

### 참고변수 (군집화 미투입, 결과 파일에는 포함)
`이면도로 여부`, `반경내총면수`, `반경100m_단속카메라개수`, `commercial_overlap`

> 이 네 변수는 이진(0/1) 또는 0값이 대부분인 이산형 변수로, 군집화에 포함할 경우
> 거리 계산을 지배해 연속변수 간 차이가 소거되는 현상이 반복 확인되어 제외함.
> (K-평균/Gower 거리 등 여러 방식으로 시도했으나 근본 해결되지 않아, 최종적으로
> 순수 연속변수만 군집화에 사용하고 이산형 변수는 사후 해석용으로 전환함)

### 출력 (`outputs/`)
- `boxplot.png`, `corr_heatmap.png`, `vif.csv` — 진단용
- `dendrogram.png`, `silhouette.png` — 군집 수 결정 근거
- `cluster_profile.csv`, `cluster_heatmap.png` — 군집 해석용
- `final_result.csv` — 포인트별 결과 (다음 단계 입력)

## step10_policy.py

`final_result.csv`를 이어받아 아래를 수행함.

1. **위험신호개수** 산출: 참고변수 중 이산형 항목(`반경100m_단속카메라개수`, `commercial_overlap`)을
   각 1점으로 환산해 단순 합산 (가중치 없음)
2. 군집별 참고변수 평균 재확인
3. 군집1("구조적 압박형") 내부를 `commercial_overlap` 기준으로 A(시간이동형)/B(공간이동형)로 세분화
4. 군집0/2에 대해서도 정책유형(저위험/C) 라벨 부여
5. `outputs/final_result_v2.csv` 저장 (최종 정책유형 포함)

### 최종 정책유형 (실행 결과 기준)
| 유형 | 개수 | 판정 근거 |
|---|---|---|
| 저위험(상시관리형) | 80 | 군집0 — 차로 여유, 혼잡 변화 적음 |
| B(공간이동형) | 14 | 군집1 중 상권중첩=0 |
| A(시간이동형) | 5 | 군집1 중 상권중첩=1 |
| C(구조적 제약형) | 6 | 군집2 — TTI 급증·대안주차 전무·단속압박 동시 발현 |

## 방법론 참고사항

- PCA 미적용: 투입 변수가 6개 수준으로 적어 원변수 기준 해석이 정책적으로 더 유용
- 통계적 최적 군집 수는 k=5(실루엣 0.301)이나, 정책 해석 가능성을 고려해 k=3 채택
- 군집2·군집1-A 일부 포인트의 변수값이 동일하게 나타나는 것은, 분석 포인트 단위와
  원자료의 도로 링크 단위가 달라 여러 포인트가 하나의 측정값을 공유하기 때문
